# Google Sheets: краткая настройка

Для v10 нужен Service Account — отдельный технический аккаунт Google, которому можно дать доступ к таблице.

1. Откройте Google Cloud Console.
2. Создайте проект или выберите существующий.
3. Включите Google Sheets API.
4. Создайте Service Account.
5. Создайте JSON key для Service Account и скачайте его.
6. Положите JSON в `secrets/google-service-account.json`.
7. Откройте вашу таблицу `Журнал Р 26-1` → «Настройки доступа».
8. Добавьте email Service Account как `Редактор`.
9. Возьмите ID таблицы из адреса:

```text
https://docs.google.com/spreadsheets/d/ВОТ_ЭТОТ_ID/edit
```

10. Запишите ID в `.env`:

```env
GOOGLE_SHEETS_ENABLED=1
GOOGLE_SHEETS_SPREADSHEET_ID=ВОТ_ЭТОТ_ID
GOOGLE_SERVICE_ACCOUNT_JSON=/app/secrets/google-service-account.json
GOOGLE_GRADES_SYNC_MINUTES=60
```

## Формат вкладок

Одна Google-таблица может содержать много вкладок. Название вкладки должно совпадать с дисциплиной из бота:

```text
Русский язык
Литература
Математика
Ин. язык
Информатика
Физика
Химия
Биология
История
Обществознание
География
...
```

Внутри вкладки:

```text
A                 B                         C          D          E
№                 ФИО Обучающегося          12.09.2026 26.09.2026 ...
1                 Аносов Владимир ...       5          Н
2                 Бакин Станислав ...                  4
```

Допустимые значения ячеек: `1`, `2`, `3`, `4`, `5`, `Н`, `Б`, `О`, `+`.

Пустая ячейка означает отсутствие оценки. При следующей синхронизации такая старая оценка будет удалена из локального кэша.
