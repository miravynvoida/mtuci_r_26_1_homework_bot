# Электронный дневник Р 26-1 — v10

Telegram-бот + Telegram Mini App для расписания, домашних заданий, учебников и просмотра оценок.

## Что изменено в v10

- бот и Mini App запускаются отдельными процессами; supervisor перезапускает упавший процесс;
- общий слой конфигурации и БД вынесен в `core/`;
- Google Sheets стал единственным источником оценок;
- редактор оценок полностью удалён из Mini App;
- синхронизация оценок выполняется раз в 60 минут и доступна вручную из админ-панели;
- поддерживаются вкладки Google Sheets по названиям дисциплин;
- поддерживается формат журнала с ФИО в колонке B и датами с колонки C;
- старые локальные оценки удаляются миграцией один раз;
- в Mini App добавлен раздел «Учебники»;
- учебник можно отправить себе в Telegram одной кнопкой;
- добавлено создание ДЗ из Mini App;
- при создании ДЗ с файлом бот ожидает следующий файл от администратора и автоматически прикрепляет его;
- при создании ДЗ через бота даты предлагаются автоматически из расписания дисциплины вместе с типом пары (`ЛЕК`, `ПР`, `ЛАБ`);
- исправлен разбор дат `ДД.ММ.ГГГГ` в Mini App (`Invalid Date`);
- добавлен полноценный выбор произвольной даты в расписании студента и администратора;
- добавлено удаление отдельных файлов из ДЗ в Telegram-боте.

## Google Sheets

Используется **одна Google-таблица с несколькими вкладками**. Название вкладки должно совпадать с названием активной дисциплины в БД.

Ожидаемый формат вкладки:

- `A` — номер студента/порядковый номер;
- `B` — `ФИО Обучающегося`;
- `C` и далее — даты занятий;
- ячейка на пересечении студента и даты — `1`, `2`, `3`, `4`, `5`, `Н`, `Б`, `О` или `+`.

Например:

```text
| № | ФИО Обучающегося       | 12.09.2026 | 26.09.2026 |
|---|------------------------|------------|------------|
| 1 | Аносов Владимир ...    | 5          | Н          |
| 2 | Бакин Станислав ...    |            | 4          |
```

Можно иметь несколько одинаковых дат в разных колонках — они сохраняются как отдельные колонки журнала.

### Подключение

1. В Google Cloud создать проект.
2. Включить **Google Sheets API**.
3. Создать **Service Account**.
4. Создать для него JSON-ключ.
5. Положить JSON в `secrets/google-service-account.json`.
6. Открыть Google-таблицу → «Настройки доступа» → добавить email сервисного аккаунта как **Редактор**.
7. В `.env` указать:

```env
GOOGLE_SHEETS_ENABLED=1
GOOGLE_SHEETS_SPREADSHEET_ID=ID_ТАБЛИЦЫ
GOOGLE_SERVICE_ACCOUNT_JSON=/app/secrets/google-service-account.json
GOOGLE_GRADES_SYNC_MINUTES=60
```

`ID_ТАБЛИЦЫ` — это часть URL между `/d/` и `/edit`.

Администраторы меняют оценки только в Google Sheets. Mini App выполняет только чтение.

## Запуск

```bash
cp env.example .env
# заполнить BOT_TOKEN, ADMIN_IDS, MINI_APP_URL и Google-настройки
python main.py
```

`main.py` — supervisor. Он запускает:

- `bot_app.py` — Telegram-бот + уведомления + синхронизация Google Sheets;
- `web_runner.py` → `web_app.py` — FastAPI/Mini App.

Если один процесс завершился с ошибкой, supervisor запускает его заново, не останавливая второй.

## Важное

`data/` и `secrets/` не должны попадать в Git. В архиве нет реального Google Service Account JSON и нет рабочей БД.
