# Telegram-бот для домашних заданий колледжа

Готовый бот на Python + aiogram 3 + SQLite.

## Возможности
- Проверка студента по ФИО из Excel.
- После успешной проверки Telegram ID привязывается к студенту.
- Красивое главное меню с приветствием.
- `📖 Учебники` и `📝 Домашнее задание` в первом ряду.
- `🗓 Расписание` ведёт в `@vvfsched_bot`.
- `🆘 Помощь` ведёт к `@miravynvoida`.
- Дисциплины в два столбца.
- Дисциплины с активным ДЗ автоматически поднимаются вверх.
- Кнопка дисциплины получает суффикс `| 📝 Есть ДЗ`.
- ДЗ: текст, пояснение, дата публикации, дата сдачи, несколько файлов/фото/видео.
- Уведомление зарегистрированных студентов о новом ДЗ.
- Раздел учебников показывает ученикам только дисциплины, у которых есть учебники и для которых раздел включён администратором.
- В админ-панели можно отдельно включать/выключать показ учебников по каждой дисциплине.
- Можно добавлять несколько учебников и удалять конкретный учебник, не затрагивая остальные.
- Админ-панель работает полностью из Telegram.
- SQLite-база создаётся автоматически как `bot.db`.

## Excel
Файл `students.xlsx` имеет структуру:
- **A** — студенты;
- **B** — пустой;
- **C** — дисциплины.

Чтобы добавить новых студентов, просто добавьте их ФИО в столбец **A**. Затем загрузите обновлённый `students.xlsx` на хостинг/в Git-репозиторий и выполните новый деплой или перезапустите бота.

Импорт добавляет новые записи и не удаляет уже существующих студентов. Это позволяет не потерять привязанные Telegram ID.

## Запуск

1. Установить Python 3.12 (рекомендуется) или совместимую версию Python 3.
2. Создать бота через @BotFather и получить токен.
3. Скопировать `.env.example` в `.env`.
4. В `.env` указать:
   - `BOT_TOKEN`
   - `ADMIN_IDS` — Telegram ID администраторов через запятую.
5. Положить `students.xlsx` рядом с `bot.py`.
6. Установить зависимости:
   `pip install -r requirements.txt`
7. Запустить:
   `python bot.py`

При первом запуске создаётся `bot.db`, а данные из Excel импортируются.

## Админ-панель

В Telegram отправьте боту:
`/admin`

Доступ получают только Telegram ID из `ADMIN_IDS`.

В разделе `📖 Учебники` администратор может:
- открыть конкретную дисциплину;
- добавить несколько учебников;
- удалить конкретный учебник;
- включить/выключить показ учебников этой дисциплины ученикам.

Если раздел учебников выключен, дисциплина не появляется в пользовательском разделе `📖 Учебники`, даже если в базе остались её учебники. Их можно включить обратно в любой момент.

## Переменные окружения

```env
BOT_TOKEN=PASTE_BOT_TOKEN_HERE
ADMIN_IDS=123456789
DB_PATH=bot.db
STUDENTS_XLSX=students.xlsx
```

## Даты

В боте используются только даты `ДД.ММ.ГГГГ`, без времени.
Дата публикации ставится автоматически при создании ДЗ.
Срок сдачи вводится администратором.

## Важно

Не публикуйте `.env` и токен бота в Git. Если токен был раскрыт, перевыпустите его через BotFather.

Telegram-файлы ДЗ и учебников сохраняются как `file_id`, поэтому серверу не требуется хранить копии этих файлов.
